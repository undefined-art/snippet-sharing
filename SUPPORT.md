# Support

Thank you for using this project. Here is how to get help:

## Documentation

- [README.md](./README.md) — setup, configuration, and usage
- [CONTRIBUTING.md](./CONTRIBUTING.md) — how to contribute
- [CHANGELOG.md](./CHANGELOG.md) — release history

## Getting Help

- **Bugs and feature requests**: open an issue using the
  [issue templates](https://github.com/undefined-art/snippet-sharing/issues/new/choose).
- **Questions**: start a discussion under the
  [Discussions](https://github.com/undefined-art/snippet-sharing/discussions) tab if enabled,
  otherwise open an issue labelled `question`.

## Security

For security vulnerabilities, please follow the process described in
[SECURITY.md](./SECURITY.md). Do **not** report security issues publicly.

## Commercial / Priority Support

For commercial support, onboarding, or priority response, contact the
maintainers directly through the repository profile.
